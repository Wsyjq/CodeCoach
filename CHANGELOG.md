## [0.1.0] - 2026-08-11

### Added

- React learning workspace and FastAPI backend.
- Knowledge QA, problem understanding, hints, code debugging, data QA, and review flows.
- Local authentication, SQLite learning memories, review scheduling, and statistics.
- First-party MIT knowledge cards, local retrieval, and an optional vector-store adapter.
- Optional OpenAI-compatible LLM integration with deterministic fallback.
- Docker deployment, automated tests, CI, CodeQL, and community health files.
